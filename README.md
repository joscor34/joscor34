## 🧬 Enfoque profesional

Soy **ingeniero en nanotecnología** con énfasis en:

- **Nanomateriales y nanotransportadores** (incluyendo nanotoxicología)
- **MEMS y sistemas de sensores** para aplicaciones biomédicas y ambientales
- Materiales avanzados para **tratamiento de agua** y remediación

Como **MEMS specialist**, me interesa todo el ciclo:
- Diseño conceptual de dispositivos
- Selección de materiales funcionales (conductores, polímeros, nanocompuestos)
- Integración con electrónica, microcontroladores y sistemas de adquisición de datos

En paralelo, trabajo como **desarrollador de software** construyendo:

- Plataformas educativas y dashboards para análisis de datos
- Aplicaciones web y móviles
- Proyectos de IoT con microcontroladores y visión por computadora

Me gusta conectar el mundo **nano** con el mundo **software**: desde simular y analizar materiales, hasta convertir datos experimentales en interfaces claras y usables.
